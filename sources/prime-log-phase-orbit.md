# Source map: prime-log phase orbit

## Artifact

[The public artifact](../artifacts/prime-log-phase-orbit/README.md) states one bounded deduction: for distinct primes, the relative log frequencies have no integer relation, so the continuous-time phase trajectory is dense in the equal-amplitude phase-state torus; continuity transfers the same worst-case global fidelity for any fixed cloning channel from the orbit to the full family.

## Claim-to-source map

| Claim | Source or derivation | Limit |
|---|---|---|
| Equal-amplitude phase states are considered for cloning | Herasymenko et al., [arXiv:2610.06723v1](https://arxiv.org/abs/2610.06723), Eq. 10 and Theorem X.1 | The phase-state optimum is for worst-case global fidelity; trace-distance optimality remains open |
| Relative prime-log frequencies have no nonzero integer relation | Exponentiation and unique-factorisation derivation in the artifact | Applies to any fixed finite set of distinct primes |
| The continuous-time orbit is dense | Character-average proof in the artifact | Does not assert a finite-time cover or convergence rate |
| All-time worst-case channel fidelity agrees with the full-family value | Continuity on the compact torus plus density | Fixed deterministic channel; global fidelity; same channel class on both sides |
